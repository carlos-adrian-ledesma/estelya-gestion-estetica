# Privacidad — ESTELYA CORE FREE candidata

- Arquitectura local-first. Los registros, imágenes y consentimientos administrados pertenecen al establecimiento usuario.
- No existe telemetría de red habilitada ni backend propio para recibir métricas.
- Los logs locales pueden contener mensajes de excepción; revisarlos antes de compartirlos.
- El cifrado de base es selectivo; adjuntos y nombres no están necesariamente cifrados.
- No utilizar esta versión con datos clínicos reales hasta terminar validación legal/técnica.
- No compartir ZIP de perfil comercial ni capturas sin anonimizar.
- Durante demo se generan y borran datos completamente ficticios, sin utilizar la base persistente.

Este documento es preliminar y no reemplaza una política de privacidad legal definitiva.
